# 011.8 NETWORK RESILIENCE
Moderation synchronization now applies bounded exponential backoff with jitter on errors (10–120 seconds, normal interval 10 seconds) and requires an explicit JSON boolean true acknowledgement with a maximum response size of 1024 bytes. Failed events remain in SQLite and are sent in sequence after recovery. Four regression tests cover acknowledgement validation, durable ordered recovery, delay bounds and reset after successful synchronization. 55 selected Python tests and 59 JavaScript tests passed. No UI, schema, credentials or other network flows changed. Backoff may extend moderation propagation delay during outages; a permanently rejected event can still block the queue. Live Telegram/Cloudflare, end-to-end timing and deletion retries not tested. No automatic retries introduced for payments or account deletion. Existing socket timeout is not an end-to-end deadline.
