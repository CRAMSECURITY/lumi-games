# LUMI 008.7 SECURITY CORE — этап 1

Изменения: лимит 120 авторизованных API-запросов на пользователя за календарную минуту (D1, атомарный UPSERT), атомарный лимит пяти созданий комнат за 10 минут, отклонение auth_date из будущего более чем на 30 секунд, заголовки защиты, часовая очистка счетчиков и комнат/ответов без обновлений 30 суток, удаление счетчиков при удалении аккаунта. Дизайн, Python-бот, графика и игровой баланс не менялись. Политика хранения 30 суток выбрана для временных игровых комнат; согласовать перед production.

## Обновление
1. Сохранить резервные копии D1 и SQLite, не заменять рабочую базу или .env.
2. Сначала проверить на отдельном staging Worker и отдельной D1, не использовать реальные пользовательские данные. Из 02_MINI_APP: npm ci, npm test, npx wrangler d1 migrations apply lumi-games-db --local. Для удаленной staging/production базы проверить имя и ID в конфигурации; затем применить миграции командой npx wrangler d1 migrations apply lumi-games-db --remote и только затем npx wrangler deploy. Не запускать на production до проверки staging. Миграция 0002 обязательна.
3. Проверить Telegram iOS/Android/Web, авторизацию, повторное подключение, создание комнат, ответы, удаление, заголовки и cron. CSP использует unsafe-inline ради совместимости старого интерфейса; проверить загрузку ресурсов и реальное применение _headers. Не считать CSP полной защитой XSS.
4. Python: установить requirements.txt в отдельном окружении и повторить pytest. В текущей среде aiogram отсутствует; выполнен только синтаксический анализ. JS: 28 тестов, включая интеграцию SQLite с проверкой лимита и очистки. Реальные D1/Telegram не проверены.

## До публичного релиза
- Единая блокировка и возрастной допуск между ботом и Worker, с отказом при недоступности источника авторизации.
- Защита до HMAC и D1 (Cloudflare WAF/rate limiting), нагрузочные тесты и бюджетные лимиты. D1-лимит сам потребляет записи; не защищает от распределенного DDoS.
- Шифрование резервных копий, тест восстановления, очередь удаления и повторов, отдельные ключи внутренних API, ротация секретов.
- Антифрод платежей, верификация возраста с учетом приватности, жалобы, модерация, блокировки, защита от преследования.
- Серверный античит и случайные задания, аудит зависимостей по актуальной базе CVE, тесты реальных устройств, мониторинг и откат.
- Проверка требований GDPR и сроков хранения. Не обещать абсолютную безопасность.
