# 010.3 DEPENDENCY GATE
Изменены только инструменты проверки и документация. Код приложения и зависимости не изменены.
Проверено 133 записи npm lock: HTTPS, разрешенный registry.npmjs.org, формат SHA-512 и совпадение прямых зависимостей manifest/lock. Это не проверка содержимого скачанных пакетов или CVE. 6 тестов инструмента, 41 JS тест прошли.
Запуск офлайн: python 04_TOOLS/dependency_gate.py --offline. Для онлайн-проверки установить pip-audit в отдельное доверенное окружение, иметь npm и доступ к сети, запустить python 04_TOOLS/dependency_gate.py (или 05_DEPENDENCY_AUDIT.bat). Любой ненулевой результат сканера блокирует успешный результат проверки. Инструмент не запускается автоматически при deploy. Не считать offline-результат разрешением релиза.
Python зависимости пока не зафиксированы точными версиями и хешами; pip-audit разрешает диапазоны из requirements, поэтому результат не подтверждает версии production. Необходимо создать lock в целевом окружении и проверить его отдельно. Онлайн CVE-аудит не выполнен в этой сборке. Необходимо проверить реальные TLS, нагрузку, полное шифрование БД и Telegram. Дизайн не изменен.
