# 011.9 SELF-HEALING SYSTEM
Four long-running loops (ban synchronization, maintenance, reminders, admin events) are supervised. Unexpected exceptions or returns trigger restart with exponential delay 5–120 seconds, reset after 300 seconds of runtime. Cancellation propagates and all supervisor tasks are collected on shutdown. Supervisor logs only fixed loop labels and exception class, not exception messages. Existing internal loop logging unchanged. No migration or UI changes. 47 selected Python tests (including 4 new supervisor tests), 59 JavaScript tests passed. No live Telegram, hung-task watchdog, process crash recovery or exactly-once notification guarantee; cancellation does not stop already running to_thread operations. Persistent failures still require operator action.
