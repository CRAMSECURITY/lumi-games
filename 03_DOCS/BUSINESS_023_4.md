# 023.4 BUSINESS CONNECT — pilot
Apply D1 migration 0007_business_connect.sql after 0006 in staging. Set LUMI_BUSINESS_DIRECTORY=1 and LUMI_BUSINESS_CONNECT=1 only for controlled tests. Approved profiles can send, accept, decline and cancel invitations; no contact details or Telegram IDs are exposed. Both participants must have approved cards and not be globally banned. Changes to a card or withdrawal remove related invitations. The nominal limit is 10 outgoing invitations per 24 hours, but withdrawal/edit removes history and can reset the limit. One invitation per pair until card change; no direct messages, pair-specific blocking, reporting or notifications yet. Global bans hide invitations while active, not permanent revocation. List limited to 50. No age changes. Do not enable publicly before abuse controls and live tests. Local Node tests 75/75, including one new API integration test. No Python regression or live Telegram/D1 testing. Owner signature required.
