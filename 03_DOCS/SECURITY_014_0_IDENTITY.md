# 014.0 Identity & profile security
Moderator decision buttons now carry a random 96-bit review ID. Both bots share an atomic conditional update and write audit records within the caller's transaction. Old buttons cannot decide newer submissions; invalid callbacks and missing profiles are rejected. The admin dashboard no longer offers approval without the original review materials. Failed delivery only removes its own review. Automatic SQLite migration adds review_id; legacy pending reviews without an ID are cancelled and must be submitted again. Stop both bots, back up SQLite, start the main bot first to migrate, then restart the admin bot. No D1 migration. Not proof of age or genuine identity; no biometric recognition, duplicate media detection or live Telegram test. Archive requires owner signature. Offline Python and Node tests passed.
