# LUMI 010.1 — Release readiness
Изменение поверх 010.0 RC. Worker /api/health теперь проверяет наличие всех шести обязательных таблиц через sqlite_master, наличие BOT_TOKEN, ключа синхронизации блокировок и edge rate limiter. HTTP 503 при неготовности, 429 при превышении лимита; HTTP 200 только при прохождении этих проверок. Ошибки D1 и секреты не раскрываются. Это проверка наличия таблиц, не полная проверка столбцов, индексов, валидности секретов и работоспособности Telegram. Мониторинг должен считать 503/429 ошибкой. Новых миграций нет.

Локально: 37/37 JS тестов (Node 22.16.0, SQLite-имитация D1), включая отсутствие миграции, ключей, ошибку БД и лимит health. Python-код и дизайн не изменены. Полный runtime aiogram, актуальные CVE, реальный Cloudflare, платежи, мобильные устройства, нагрузка, независимый пентест и шифрование рабочей БД не проверены/не завершены. Не разворачивать на production без staging. Инструкции 010.0 RC сохраняются.
