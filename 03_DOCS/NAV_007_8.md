# LUMI 007.8 — Obsidian navigation

- 02_MINI_APP/public/genesis.css: панель навигации и оформление центра аккаунта.
- 02_MINI_APP/public/telegram-nav.js: шесть разрешённых переходов, подтверждение, запасное копирование команды, тактильный отклик Telegram.
- 01_BOT/bot.py: обработка фиксированных deep link параметров lumi_home, lumi_gift, lumi_invite, lumi_profile, lumi_safety, lumi_notifications. Старые реферальные ссылки не изменены.
- 01_BOT/test_miniapp_links.py: проверка маршрутизации.

Прямые переходы требуют обновления также бота, не только Mini App. Telegram может попросить нажать Start. В старом боте можно отправить указанную команду вручную. Не публикуйте без резервного копирования и проверки в Telegram. Для локального просмотра используйте 01_PREVIEW.bat. Карточки героев и серверная логика Worker не менялись.

Проверено: 27 тестов Worker; офлайн-тесты бота; Chromium с встроенными локальными ресурсами на ширинах 360, 390, 1280 — пять вкладок, шесть ссылок (перехват вызова window.open, без реального перехода), 21 карточка, отсутствие необработанных ошибок. WebGL, реальный Telegram, платежи, D1 и аудит зависимостей не проверены этой сборкой.
