# LUMI GAMES 2.2 — стабильность дуэлей (26.11.2026)

Пользователь подтвердил, что после релиза HMAC 2.1 создание комнаты работает и проверка дуэли прошла нормально. В 2.2: восстановление последней комнаты на том же устройстве при доступном хранилище WebView; сетевой таймаут 10 секунд, автоматические повторные GET и восстановление при возвращении сети/видимости; сериализация запросов; локальный обратный отсчёт с серверной коррекцией; сервер пропускает истекшие раунды после офлайна обоих участников; условная запись ответа только в актуальном раунде; приглашение через Telegram с ссылкой на бота и кодом. Код по-прежнему вводится вручную. HMAC, бот, схема D1 и сохранённые данные не изменены. 18/18 тестов Node 22.16, включая SQLite in-memory и имитацию WebView через VM. Реальный Cloudflare и Telegram для 2.2 пока не проверены. Восстановление между устройствами и после очистки хранилища, автоматический вход по приглашению и идемпотентность создания комнаты при потере ответа пока не реализованы.

## Установка Windows
Распаковать ZIP в C:\LUMI, выполнить:
```powershell
cd C:\LUMI\LUMI_GAMES_STABILITY_2026-11-26
npm.cmd ci
npm.cmd test
npx.cmd wrangler deploy --keep-vars
```
Не менять .env, bot.py, lumi.db, D1 и секрет. Миграции не нужны. После публикации открыть /games, создать комнату, пригласить друга, начать дуэль; закрыть и вновь открыть Mini App, отключить/включить сеть, проверить таймер, очки и итог. При офлайне обоих игроков время продолжает идти. Следующий этап после проверки: безопасно убрать старый Friend Quest из меню, сохранив данные.
