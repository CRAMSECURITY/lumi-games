# LUMI GENESIS 1 — предварительный релиз
Содержит рабочий Worker и игры версии Stability 2.2, новый интерфейс и каталог 21 исходного героя. Изменения только в public; сервер, D1, секреты и bot.py не меняются. Каталог показывает реальные пороги открытия, но не личный прогресс. Настоящие 3D-модели и синхронизация SQLite не реализованы.

## Безопасная установка
Сохрани копию существующей папки Cloudflare. Распакуй архив в C:\LUMI, открой PowerShell:
```
cd C:\LUMI\LUMI_GENESIS_1
npm.cmd ci
npm.cmd test
npx.cmd wrangler deploy --keep-vars
```
Последнюю команду выполняй только если тесты прошли и имя Worker и D1 в wrangler.jsonc совпадают с твоим существующим проектом. Не запускай миграции, не меняй секрет BOT_TOKEN. Затем открой /games в Telegram. Если что-то не работает, опубликуй прежнюю папку тем же способом.

Проверь: каталог и фильтры, карточки, обе одиночные игры, создание и подключение комнаты с двух устройств, повторный вход, слабую сеть, возврат из фона. Настоящие устройства не проверены; попытка браузерной проверки заблокирована средой. 20 автоматизированных тестов Node прошли. FPS не измерен. Анимации CSS, WebP двух размеров, отключение polling в фоне, отсутствие постоянного WebGL-рендера.
