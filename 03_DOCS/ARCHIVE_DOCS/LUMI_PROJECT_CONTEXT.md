# LUMI — передача проекта в новый чат (27.11.2026)

## Цель и приоритет
Telegram-бот знакомств + Mini App игр и коллекционных героев. Пользователь работает в Windows, PowerShell, C:\LUMI. Нужны готовые проверенные файлы и короткие инструкции, без повторных вопросов и лишних экспериментальных версий. Тапалку, комнаты питомца, клубы, сезоны и новые механики отложить. Сначала коллекция, знакомства, игры, основной интерфейс и безопасность. Не выдавать концепты за готовое приложение.

## Единственная текущая ветка
LUMI_CORE_6_1_FIX.zip — исправленная локальная версия на основе GENESIS 6 CORE. Папка внутри архива LUMI_GENESIS_6_CORE. GENESIS 4 — последняя подтверждённая публикация Cloudflare в переписке, не удалять резервную копию. Реальное состояние текущего бота на ПК не проверено. LUMI_HANDOFF_UX3.zip — исторический снимок бота, инструкций и артов; не заменять им действующий бот автоматически. LUMI_UX3.zip — отдельно исходник bot.py и тесты от 26.11.

## Архитектура
Mini App: public/index.html (включая игровую логику), hub.js (главная/коллекция), drop-viewer.js (локальный WebGL без CDN), drop.glb, skin-geometry.json, skins/*.svg (запасные иллюстрации), catalog.js, heroes/*.webp (21 герой, два размера), genesis.css, welcome.css, welcome.js. genesis.js — старый неиспользуемый скрипт. Backend: src/worker.js, auth.js, game.js, migrations/0001_init.sql, wrangler.jsonc, package.json, tests/*.test.js. Cloudflare Worker lumi-games, D1 lumi-games-db, ASSETS, секрет BOT_TOKEN. URL https://lumi-games.kramp0884.workers.dev. Бот @Lumi_friends_bot, .env LUMI_GAMES_URL, Python/venv. Не менять токены, существующие идентификаторы героев, прогресс, привязку D1 и не запускать миграции для фронтенд-правок.

## Команды
Локальная проверка: распаковать в отдельный каталог, cd C:\LUMI\LUMI_GENESIS_6_CORE ; python -m http.server 8765 --directory public ; открыть http://localhost:8765/ . Ctrl+C останавливает сервер. Если порт занят — остановить старый сервер. npm test в папке Mini App. Локально нет настоящей авторизации Telegram; онлайн-функции проверяются в Telegram. Бот: cd C:\LUMI ; python bot.py (активировать имеющуюся .venv при необходимости). Публикация только после проверки: в том же PowerShell $env:CLOUDFLARE_API_TOKEN = Read-Host "API Token" -MaskInput ; $env:CLOUDFLARE_ACCOUNT_ID = Read-Host "Account ID" ; npx.cmd wrangler deploy --keep-vars . Ранее токен был active, но /memberships давал 10001, явный Account ID исправил ошибку. Не просить пользователя присылать токен.

## Дизайн
Главный ориентир — приложенные references: MEET. PLAY. CONNECT., премиальные карточки SHIRO/KAIRO/MIYU, MEME-DAO × TriForma, глубокий чёрный/фиолетовый, розово-сиреневые акценты, качественная графика, крупная типографика, SVG-иконки, продуманная композиция. Лайм был экспериментом для тапалки, не обязательная палитра основной версии. Предпочтение пользователя — не однотонные карточки, не случайные картинки, не примитивная 3D-геометрия и не изображения со следами интерфейса. Маскот основного приложения — капля; выбранный матовый Art Toy относится к отложенной тапалке. Не путать. Нужны непрерывная анимация, вращение пальцем, реакции, без обрезания и лишних кнопок. 21 герой и 6 образов маскота — отдельные коллекции. Сохранить реальные ранги каталога, не переименовывать их на основании концептов.
