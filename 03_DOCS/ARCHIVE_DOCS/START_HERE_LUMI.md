# GENESIS 4 — установка
Распакуйте архив в C:\LUMI. В PowerShell:
```
cd C:\LUMI\LUMI_GENESIS_4
npm.cmd ci
npm.cmd test
npx.cmd wrangler deploy --keep-vars
```
Публикуйте только после проверки, что Worker и D1 совпадают с текущими. Закройте Mini App и откройте /games заново. Маркер GENESIS / 004.
Бот, .env, SQLite, D1 и серверный код не менялись. Главное меню и 3D-капля теперь локальные. 6 вариантов материала — предпросмотр, не награды. 21 герой перечислен без прежних фотографий; полноценные GLB пока отсутствуют. Подарки, приглашения и знакомства открываются через бота. Браузерная проверка не выполнена: Chromium блокирует навигацию в данной среде. Автоматические тесты Node и численная проверка кадрирования выполнены.
