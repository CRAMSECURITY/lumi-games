# LUMI GAMES 2.0 — игры в Telegram Mini App

**Что сделано:** отдельный HTML-интерфейс с дуэлью двух игроков на разных устройствах (одна комната, пять раундов), очками, серверным таймером, сохранением ответов в Cloudflare D1 и авторизацией посредством проверенного Telegram `initData`. Есть две одиночные утренние игры: «Найди пары» и «Дзен-пазл». Сервер не принимает от клиента правильный ответ и итог дуэли; результат вычисляется на сервере. Пользовательские результаты утренних игр считаются недоверенными и **не участвуют в рейтинге или платных наградах**.

**Что не сделано:** интеграция с общей базой `lumi.db`, таблица лидеров, подарки, уведомления и готовые ссылки-приглашения через `startapp`. Для дуэли друг вручную вводит код комнаты. Визуальное обновление происходит опросом сервера каждые 2,5 секунды — не WebSocket. Нагрузочный/полевой тест двух реальных Telegram-клиентов ещё не проводился.

## Требования

- Node.js 20+ и npm на Windows (проверьте `node -v` и `npm -v` в терминале VS Code).
- Доступ к Cloudflare под **тем же аккаунтом**, где размещена текущая LUMI Mini App (`lumi-games.kramp0884.workers.dev`).
- Telegram-бот LUMI 4.2 с уже работающей кнопкой `/games`.
- Доступ к секретному токену своего Telegram-бота **локально**. Не вставляйте его в чаты, GitHub, `index.html` или `wrangler.jsonc`.

## Установка (VS Code → Терминал PowerShell)

**Не заменяйте `C:\LUMI\bot.py`, `.env` и `lumi.db`!** Эта сборка полностью отдельная.

1. Распакуйте архив, например в `C:\LUMI\LUMI_GAMES_2_0`. В терминале откройте эту папку: `cd C:\LUMI\LUMI_GAMES_2_0`.
2. Выполните `npm install`, затем `npx wrangler login` и войдите в тот Cloudflare-аккаунт, где находится текущий Worker.
3. Выполните `npx wrangler d1 create lumi-games-db`. В ответе получите `database_id`. Откройте `wrangler.jsonc` и замените строку `REPLACE_WITH_YOUR_D1_DATABASE_ID` на настоящий UUID базы D1. **Не изменяйте прочие поля**, особенно `name: lumi-games`.
4. Выполните `npx wrangler d1 migrations apply lumi-games-db --remote` — команда создаст таблицы комнат, ответов и утренних игр в D1.
5. Введите `npx wrangler secret put BOT_TOKEN` и на запрос вставьте токен вашего Telegram-бота. Wrangler передаст его в **секретные переменные Worker**; токен не должен попадать в репозиторий. Это отдельная настройка от локального `.env`.
6. Прогоните тесты: `npm test`.
7. Выполните `npx wrangler deploy`. Deployment заменит код **только Worker `lumi-games`** и его статические файлы в вашем аккаунте. Обычный Python-бот на ПК останется нетронутым.
8. Откройте `https://lumi-games.kramp0884.workers.dev/` и проверьте утренние игры. Затем в Telegram откройте LUMI → `/games`, создайте дуэль; друг должен открыть `/games` у себя и вставить код.

**Важно:** существующий Cloudflare Worker будет обновлён, поэтому перед шагом 7 сохраните копию текущего `index.html` или старого проекта. Если у вас другой Cloudflare-аккаунт, остановитесь перед `deploy`: иначе появится новый Worker не там, где расположен действующий сайт.

## Проверка ошибок

- **«Нет данных Telegram»:** игра открыта напрямую из браузера. Для онлайн-дуэлей открывайте через кнопку Web App внутри Telegram.
- **«D1 не настроена»:** проверьте UUID и миграции.
- **«Секрет BOT_TOKEN не настроен»:** снова выполните `npx wrangler secret put BOT_TOKEN`.
- **«Неверная подпись Telegram»:** убедитесь, что в Cloudflare Worker установлен токен именно того бота, который открывает Mini App.
- **`workers.dev` другой:** проверьте, что вы вошли в исходный Cloudflare-аккаунт, и `name` в `wrangler.jsonc` равен `lumi-games`.

## Безопасность

`initData` проверяется на сервере HMAC SHA-256 по документации Telegram. Сервер отвечает только участникам комнаты. Два человека не могут отвечать друг за друга. Нельзя отправить ответ на прошедший раунд или изменить его после отправки. Клиентский `initData` не должен логироваться и храниться в сторонних сервисах. Для серьёзного продакшена рекомендуется добавить ограничения частоты запросов на уровне Cloudflare WAF/Worker и отдельную очистку старых комнат (например, по Cron Trigger).

## Архитектура

- `public/index.html` — UI клуба, утренние игры, HTTP-клиент дуэли.
- `src/auth.js` — проверка пользователя Telegram.
- `src/game.js` — задания и серверное начисление баллов.
- `src/worker.js` — API, комнаты, серверные проверки.
- `migrations/0001_init.sql` — схема D1.
- `wrangler.jsonc` — конфигурация Cloudflare Worker.

API: `POST /api/rooms`, `POST /api/join`, `GET /api/room?code=...`, `POST /api/answer`, `GET/POST /api/morning`. Все маршруты требуют заголовка `x-telegram-init-data`.
