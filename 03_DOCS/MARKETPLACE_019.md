# 019.0 Marketplace prototype
Standalone offline Python module `01_BOT/lumi_marketplace.py`. Three provisional cosmetic SKUs, demo credits only. No actual payments, UI, authentication, user eligibility, deletion integration or production migration. Run `python -B -m unittest -v test_marketplace` from 01_BOT. Eight tests cover purchase, replay, duplicate ownership, conflict, insufficient funds, malformed input, rollback and 32 competing purchases. Authenticated identity must be supplied by a future server integration; do not expose this module directly. Use disposable SQLite only. No EXP or Stars conversion. No real funds. Next: design inventory/account deletion and authenticated catalog integration; actual sales require verified Telegram payment and refund workflows. Existing 018 code and age settings unchanged. Full regression and production tests not run.
