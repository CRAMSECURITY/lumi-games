# 018.0 — эксперимент рекомендаций
Локальный алгоритм, не ML/LLM. По умолчанию выключен. Для закрытой беты установите LUMI_MATCHING_EXPERIMENT=1 в окружении бота. Возврат к прежней сортировке: удалите флаг и перезапустите бот. Обязательные фильтры eligible_candidates, порядок новых/пропущенных анкет, возраст, блокировки и Premium-бонус не изменены. Эксперимент ранжирует уже отобранные анкеты по нормализованному пересечению интересов (до 60 баллов) и городу (40); возраст не участвует в экспериментальном рейтинге, но обязательные возрастные фильтры остаются. Баллы не являются вероятностью совместимости. Нет внешних запросов, новых таблиц или UI. 7 тестов алгоритма прошли; реальный Telegram, интеграционные тесты и влияние на качество знакомств не проверены. Перед включением оценить качество и нагрузку на закрытой бете; свободный текст может содержать чувствительные сведения, не использовать для выводов о чувствительных характеристиках. Не выдавать алгоритм за обученный AI.
