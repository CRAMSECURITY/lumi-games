# 012.9 SECURITY RELEASE GATE
Запуск: `06_RELEASE_GATE.bat` или `python 04_TOOLS/release_gate.py` из корня проекта. Используйте отдельное виртуальное окружение с установленными зависимостями и pip-audit. Node.js и npm должны быть доступны в PATH.
Локальная диагностика: `python 04_TOOLS/release_gate.py --offline`. Код 2 означает успешную локальную диагностику без разрешения выпуска; 1 — ошибка; 0 — автоматические проверки в строгом режиме прошли, но ручная проверка всё ещё обязательна. Скрипт не публикует проект и не подключён к CI или wrangler deploy. Тайм-ауты 300 секунд на проверку, 420 на аудит зависимостей.
Локально: 126 тестов бота, 60 JS, 11 инструментов (5 новых); 133 записи npm lock. Онлайн CVE-аудит не выполнен, aiogram и pip-audit отсутствуют в данной среде. Полноценный тест Telegram, Cloudflare/TLS, платежей, нагрузочный тест и независимый пентест остаются обязательными до релиза. Python requirements пока используют диапазоны версий; аудит разрешённых зависимостей не доказывает безопасность фактически развёрнутого окружения.
