# 013.1 SUPPLY CHAIN SECURITY
Подпись ZIP: Ed25519 над SHA-256 содержимого с фиксированным доменом. Проверять до распаковки, доверенным внешним скриптом и ключом, полученным независимо. Ключ из самого проверяемого архива доверенным не считается.

Для этой сборки предоставлены отдельные public key, signature и verifier. Ключ одноразовый, не является постоянным ключом издателя. Сверьте SHA-256 публичного ключа с сообщением о выпуске. Для следующих релизов владелец должен создать собственную пару на доверенном компьютере и хранить закрытый ключ вне проекта, с ограниченными правами, предпочтительно в защищённом хранилище. Сырые закрытые ключи не зашифрованы; не отправляйте их в чат.

Команды (Python с cryptography):
- `python release_signature.py verify LUMI_013_1_SUPPLY_CHAIN_SECURITY.zip LUMI_013_1_PUBLIC.bin LUMI_013_1_SIGNATURE.sig`
- `python release_signature.py generate /secure/release.lumi-private /secure/release.pub`
- `python release_signature.py sign NEW.zip /secure/release.lumi-private NEW.sig`

Проверка подписи не доказывает отсутствие уязвимостей, не защищает от отката к старой подписанной версии и не заменяет онлайн-аудит. Проверка внешней подписи пока ручная; внутренний release gate не проверяет исходный ZIP. Не запускайте скрипт из недоверенной сборки для её проверки.
