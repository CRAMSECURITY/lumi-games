# 013.4 Business continuity
Run from 01_BOT: `python lumi_continuity.py BACKUP_DIRECTORY PRIVATE_WORKSPACE --max-age-hours 36` with LUMI_BACKUP_KEY in the environment. Nonzero exit means not ready; connect to your scheduler and alerting. The newest eligible backup must pass the existing recovery drill. Freshness uses filesystem modification time, not authenticated snapshot creation time. Copying a backup can change this time; do not treat it as a guaranteed recovery point. Use private encrypted storage and an independent off-site copy. On Windows configure ACLs separately. No live database changes, infrastructure failover, D1 restoration or alert integration are performed. Archive is unsigned until signed with the owner's pinned key.
