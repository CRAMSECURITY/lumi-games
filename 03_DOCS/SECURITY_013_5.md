# 013.5 Production observability
From 01_BOT run `python lumi_observability.py lumi.db`. JSON output contains aggregate daily UTC counts and local database probe latency only. Exit 0: OK, 1: degraded, 2: unavailable. Defaults: 500 ms probe latency or 20 daily errors. Configure thresholds with --slow-ms and --error-limit. Schedule under a trusted OS account with private database directory. The read-only connection can still participate in SQLite WAL shared-memory bookkeeping; no application rows are modified. A successful probe does not establish that the bot or background workers are running. No Telegram/Cloudflare network probes, external alerts or real load tests are included. Archive requires owner's signature. Only new unit tests and inventory/JS syntax checks rerun.
