# 011.6 HIGH LOAD ARCHITECTURE
Both Telegram polling entry points now call lumi_polling.bounded_polling, which uses aiogram's native pre-task concurrency limit. Defaults: 32 main bot, 8 admin bot; LUMI_POLLING_LIMIT and LUMI_ADMIN_POLLING_LIMIT accept integers 1–256. Invalid configuration or unsupported aiogram signature fails closed. Update requirements before starting. Source: https://docs.aiogram.dev/en/v3.20.0.post0/changelog.html
48 selected Python tests (including 4 new polling tests using fake dispatchers), 59 JS tests passed. No live aiogram installed; real Telegram backpressure, latency, throughput and SQLite contention not verified. Limits are per process, not global. Heavy load can delay legitimate updates. No migration or UI changes. No claim of horizontal scaling or distributed queue support.
