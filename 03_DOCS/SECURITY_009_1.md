# 009.1 ECONOMY GUARD
База: 009.0 EDGE DEFENSE. Изменены только Python-бот и документация, Mini App не изменён.
- Лимит трёх боёв пары в UTC-сутки проверяется при создании и принятии вызова под BEGIN IMMEDIATE.
- Участники боёв, Duo и ежедневных наград должны иметь анкету с заявленным возрастом 18+ и не иметь действующей блокировки аккаунта.
- Завершение Duo и запись награды теперь в одной транзакции; параллельные ответы сериализуются.
- Тренировка не начисляется повторно при откате даты; начисление EXP в той же транзакции.
- Реферальные ID ограничены диапазоном SQLite; повторное подтверждение проверяет количество изменённых строк.
- Для исхода боя используется системный генератор случайных чисел.
Новые миграции не нужны. Сохранены существующие размеры наград и лимит пары. Перед заменой работающего бота сделать проверенную зашифрованную резервную копию.
Тесты: 6 новых offline unittest (32 параллельных обращения, откат, возраст/блокировка, лимит пары, дата, рефералы); 32/32 Node; 7 других offline-скриптов завершились успешно. Синтаксис изменённых Python-файлов проверен. aiogram отсутствует: полноценные обработчики и Telegram не проверены. Тесты не доказывают отсутствие всех уязвимостей; мультиаккаунты, глобальный антифрод, реальные платежи и нагрузка не проверены. Проверка заявленного возраста не является верификацией личности. Лимит на пару не ограничивает фарм через множество партнёров. Тест отката и параллельности проверяет транзакционные примитивы на отдельной SQLite, не полный Telegram-поток.
