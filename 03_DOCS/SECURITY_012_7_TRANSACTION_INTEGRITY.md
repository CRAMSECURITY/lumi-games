# LUMI 012.7 TRANSACTION INTEGRITY

Сборка основана на 012.6. Добавлена проверка отсутствия активной глобальной блокировки непосредственно в SQL-условиях записи счётчиков API, создания комнаты, присоединения, ответа и записи результата утренней игры. При обмене данных Telegram на сессию также проверяется блокировка в самом INSERT. Это закрывает окно между предварительной проверкой блокировки и выполнением этих операций.

В интеграционный тест добавлены два сценария блокировки непосредственно перед записью результата и созданием комнаты. npm test (Node 22.16.0): 60/60, включая эти сценарии. Новые миграции не нужны. Python и клиентские ресурсы не менялись; Python-тесты не запускались.

Ограничения: тесты на локальной SQLite, не D1. Отказы при конфликте могут возвращать прежние 401/429/409, а не 403. Время проверки при обмене сессии берётся в начале запроса. Чтение и автоматическое продвижение раундов отдельно не защищены новой проверкой; синхронизация блокировок между серверами и реальная нагрузка остаются открытыми задачами.
