# LUMI 008.6 — Floating Home
Семь элементов главной получили независимое парение, объёмную кромку, тень, наклон по указателю и динамический блик. Перетаскивание не должно запускать переход; обычное нажатие сохраняет прежний обработчик. Вертикальная прокрутка разрешена. Учитывается prefers-reduced-motion. Это CSS-эффект, не новые 3D-модели.
Изменены только public/index.html и добавлены public/home-floating.css, public/home-floating.js. Серверные тесты 27/27; node --check пройден. Chromium не запустил проверку в текущей среде (тайм-аут, ошибки EGL). Проверка в Telegram и на смартфоне не выполнена. Не публиковать без staging.
