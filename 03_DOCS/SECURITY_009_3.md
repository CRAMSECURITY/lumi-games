# LUMI 009.3 SESSION SECURITY

База: 009.2 ANTI-FRAUD. Python-бот и графика не изменены.
- POST /api/session принимает подписанные Telegram initData не старше 300 секунд. Уникальный HMAC fingerprint исключает повторный обмен, включая перестановку полей. Атомарный INSERT защищает от параллельного обмена.
- API принимает только отдельный случайный 256-битный токен, хэш SHA-256 которого хранится в D1. Клиент хранит токен в памяти, не в localStorage/sessionStorage. Срок до auth_date + 3600 секунд.
- При удалении пользователя сессии отзываются, fingerprint сохраняется до истечения срока для предотвращения повторного обмена; очистка ежечасно.
- CSP hash обновлён. UI и сервер необходимо обновлять вместе.

## Обновление
В тестовой среде сначала применить миграцию 0003_sessions.sql (например, из 02_MINI_APP: npx wrangler d1 migrations apply lumi-games-db --remote, только если выбран именно тестовый D1; для локальной базы использовать --local). После проверки выполнить миграцию на рабочей базе и совместный деплой Worker + assets. Сделать резервную копию. Старые клиенты должны закрыть и заново открыть Mini App.

## Ограничения
Потеря ответа при первом обмене, перезагрузка страницы или повторное открытие с теми же initData требуют нового запуска Telegram с новым подписанным payload. Токен остаётся bearer-токеном: его кража или кража initData до первого обмена не исключены. Блокировки основного бота пока не синхронизированы. Отзыв не отменяет уже начатые запросы. Реальный Cloudflare/Telegram не тестировались, D1 имитирован SQLite. Новая схема добавляет запрос D1 на каждый вызов; нагрузку следует измерить. Сроки 5 минут и 1 час выбраны предварительно.
