# 013.9 Advanced moderation
Registration city/name/custom nickname/description and description editing now reject local scam/link indicators, invisible-only text and selected control characters. No external moderation services or new stored content. Existing profiles are not retroactively changed. False positives are possible, especially for legitimate links or educational discussion. Image, audio, duplicate-profile and age verification are out of scope. Tests: 161 Python unittest cases and 60 Node tests passed locally; no live Telegram testing. Release requires owner signature.
