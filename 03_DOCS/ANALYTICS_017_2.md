# 017.2 — Bot activity integration
Сбор выключен по умолчанию. Для тестовой среды после проверки политики приватности: LUMI_ANALYTICS_ENABLED=1 в .env. Зарегистрированный пользователь сам вводит /analytics_on; /analytics_off удаляет согласие и записи. Дни активности считаются по UTC, не более одной записи в сутки. Случайный идентификатор связан с Telegram ID отдельной таблицей в той же SQLite; это псевдонимизация, не анонимность. Удаление анкеты удаляет обе записи через триггер. Фоновая очистка хранит 90 календарных дней; резервные копии имеют отдельный срок. Отчёт: python lumi_analytics_live.py lumi.db из 01_BOT. Только завершённые дни, только согласившиеся пользователи, сообщения/нажатия бота, не Mini App. Согласие должно быть информированным до ввода команды; оператору нужно предоставить описание цели, хранения, отказа. Когортные события 017.1 остаются автономным прототипом. 6 тестов нового модуля прошли, синтаксис bot.py проверен; aiogram не установлен, интеграция в реальном Telegram и нагрузка не проверены. Перед запуском сохранить резервную копию. Таблицы создаются при init_db. Архив требует подписи владельца.
