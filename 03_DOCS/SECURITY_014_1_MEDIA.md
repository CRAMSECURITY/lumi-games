# 014.1 MEDIA SAFETY
Возрастные правила и Mini App не изменены. Ограничение известных размеров новых медиа: 19 MiB для фото/видео анкеты, голосовых, кружков и фото в чате. Неизвестный размер допускается, поскольку поле Telegram необязательно. При межботовой передаче верификации проверяется размер get_file и каждый записываемый фрагмент ограниченного буфера; буфер закрывается при исключении. Это ограничение на файл, не на общую память процесса. Сохранённые file_id не мигрируют. Не является антивирусной проверкой, проверкой MIME содержимого или детектором дубликатов; реальная интеграция Telegram не проверена. 170 Python unittest, 60 JS тестов прошли локально. Новых миграций нет. Требуется подпись ключом владельца.
